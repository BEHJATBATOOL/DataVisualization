#
Project Overview

This project was completed as part of the Data Analytics. The objective of this task was to transform raw data into meaningful visualizations using Python and Matplotlib.

Dataset

The dataset used for this project is CodeAlpha_DataVisualization.csv.

Tools and Technologies
Python
Pandas
Matplotlib
Google Colab
Visualizations Created
Sales by Category
Sales by Region
Profit by Category
Profit by Region
Sales and Profit by Category
Sales Distribution
Profit Distribution
Sales vs Profit
Key Insights

The visualizations provide a clear understanding of sales and profit performance across different categories and regions. The distribution charts show how sales and profit values are spread throughout the dataset. The Sales vs Profit visualization helps examine the relationship between sales and profitability.

Conclusion

Data visualization makes complex datasets easier to understand by presenting information through charts and graphs. The visualizations created in this project provide useful insights into sales performance, profitability, distributions, and relationships within the dataset. These insights can support better data-driven decision-making.
